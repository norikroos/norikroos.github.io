プライバシーポリシー

トリキマップ（iOS / Android）

1. 取得する情報と利用目的

  • 位置情報：現在地周辺の店舗を地図に表示するために使用します。位置情報は端末上で地図の表示にのみ使用し、開発者のサーバーに送信・保存することはありません。
  • 予約時に入力する情報（お名前・電話番号・メールアドレス）：アプリ内で表示する予約ページ（店舗の予約サービス）に送信され、予約に使用されます。次回の入力を省くため、入力内容は端末内にのみ保存されます。開発者がこれらの情報を取得・保存することはありません。
  • アプリの利用状況：機能改善のため、Google Firebase Analytics により、閲覧した店舗・検索した地名・予約操作などの利用状況と、端末・アプリの情報を収集します。

2. 広告について

本アプリでは、Google AdMob による広告を表示しています。AdMob は広告の配信・効果測定のために、端末の広告識別子（iOS の IDFA / Android の広告 ID）、IP アドレスから推定されるおおよその位置などの情報を収集する場合があります。Android では端末の設定から広告 ID をリセット・削除できます。

3. 外部サービス

本アプリは以下の外部サービスを利用しており、各サービスのプライバシーポリシーに従って情報が取り扱われます。

  • Google AdMob、Google Firebase Analytics、Google マップ / Places（Google のプライバシーポリシー）
  • 店舗の予約サービス（アプリ内で表示する予約ページの提供元）

4. 第三者への提供

上記の外部サービスを除き、本アプリが取得した情報を第三者に提供することはありません。

5. データの保存と削除

本アプリはアカウント登録を必要とせず、開発者のサーバーに個人情報を保存しません。端末内に保存された予約入力情報は、アプリを削除することで消去されます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、お問い合わせページよりお願いいたします。
