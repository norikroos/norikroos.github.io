プライバシーポリシー

すしマップ

1. 収集する情報

本アプリは、以下の情報を取得する場合があります。

  • 位置情報：現在地周辺の店舗を表示するために使用します。位置情報はお使いの端末上でのみ処理され、外部サーバーに送信されることはありません。
  • 検索キーワード：検索欄に入力した文字列は、候補を表示するために Google Places API に送信されます。最近の検索履歴はお使いの端末内にのみ保存されます。
  • 利用状況：アプリ内の操作状況（画面の表示やボタンの操作など）を、機能改善のために匿名で収集します。

2. 広告について

本アプリでは、Google AdMob による広告を表示しています。AdMob は広告配信のために端末の広告識別子（iOS の IDFA、Android の広告 ID）などの情報を収集する場合があります。広告識別子は、端末の設定からリセット・削除（iOS ではトラッキングの許可の取り消し）ができます。詳細は Google のプライバシーポリシーをご確認ください。

3. 利用状況の分析について

本アプリでは、機能改善のために Google Firebase Analytics を使用しています。Firebase Analytics はアプリ内の操作状況や端末の情報（アプリインスタンス ID など）を収集しますが、氏名やメールアドレスなど個人を特定する情報は含みません。詳細は Firebase のプライバシーとセキュリティをご確認ください。

4. 第三者への提供

上記の広告・分析・検索のサービス（Google）を除き、本アプリが取得した情報を第三者に提供することはありません。

5. データの保存

本アプリはアカウント登録を必要とせず、氏名やメールアドレスなどの個人情報を取得・保存しません。表示条件や最近の検索履歴などの設定は、お使いの端末内にのみ保存されます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、お問い合わせページよりお願いいたします。
